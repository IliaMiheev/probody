## Приложение для визуального планирования полёта дрона

Скачать приложение:
```bash
git clone https://github.com/IliaMiheev/probody.git
```

После установки проекта нужно установить зависимости:
```bash
npm i
```

Запустить приложение в режиме разработки:
```bash
npm start
```

Установить приложение на компьютер из исходников
```bash
npm run package
```

Создать установочный файл
```bash
npm run make
```
